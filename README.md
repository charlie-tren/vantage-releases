# Vantage

Market dashboards for Bloomberg Terminal users: rates, FX, credit and equities.

**[Download VantageSetup.exe](https://github.com/charlie-tren/vantage-releases/releases/latest/download/VantageSetup.exe)** - Windows 10 or 11, 135 MB.

Needs the Bloomberg Terminal open and logged in on the same machine. Vantage reads from it through the Desktop API. Nothing is sent anywhere else.

The installer is unsigned. Windows will warn the first time it runs: choose More info, then Run anyway.
